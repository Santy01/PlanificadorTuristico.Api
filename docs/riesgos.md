## Cómo se usa esta matriz

- Antes de cada entrega se revisa si cambió la probabilidad de algún riesgo, por ejemplo después de una evaluación.
- Un riesgo nuevo entra cuando ocurre algo en una prueba o en producción, con la evidencia de dónde se vio.
- Las mitigaciones «pendientes» son tareas del tablero del proyecto.
